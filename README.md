# 📚 Student Grades Analysis

## 📂 Mission 1 — Load the Data

Create a Python file.

### Tasks:

- Import pandas.
- Read students.csv.
- Store it in a DataFrame.
- Print the first 5 rows.
- Print the last 5 rows.

**Goal:** Become comfortable loading data.

---

## 🔍 Mission 2 — Inspect the Dataset

Without modifying the CSV, answer these questions programmatically:

### Tasks:

How many students are there?
How many columns?
What are the column names?
What data type is each column?
Are there any missing values?

## 📊 Mission 3 — Basic Statistics

For each subject, find:

### Tasks:

Average mark
Highest mark
Lowest mark

Don't calculate them manually—use pandas methods.

## 👨🏽‍🎓 Mission 4 — Find Students

Answer the following:

### Tasks:

Student with the highest Math mark
Student with the lowest English mark
Students scoring above 90 in Chemistry
Students failing Math (< 70)

## Mission 5 — Add New Columns

### Tasks:

Create two new columns:

Average (average of the four subjects)
Grade

Use this grading system:

Average Grade
90+ A
80–89 B
70–79 C
60–69 D
Below 60 F

Hint: You'll likely need a custom function and DataFrame.apply() (or another approach you prefer).

## 🕶️ Mission 6 — Visualization

Create three charts:

### Tasks

📊 Average mark for each subject (bar chart)
📈 Distribution of students' averages (histogram)
🥧 Grade distribution (pie chart)
